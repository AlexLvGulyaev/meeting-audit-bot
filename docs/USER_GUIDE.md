Это руководство для пользователя, который отправляет аудио/видео боту и получает аудит.

---

## 🎯 1. Что это

Meeting Audit Bot — Telegram-ассистент, который:
1. Принимает аудио или видео.
2. Транскрибирует речь через AssemblyAI с разделением по спикерам.
3. Проводит структурированный аудит по выбранному сценарию через нейросеть.
4. Возвращает результат в тот же чат.

Сценарии аудита: онбординг, онлайн-урок, клиентский чат, звонок/продажи B2B.
Активный сценарий выбирает администратор в `/admin`.

---

## 🚀 2. Первый запуск

1. Найдите бота @PEcb10_bot в Telegram и нажмите **Start**.
2. Бот пришлёт приветствие и список доступных сценариев аудита.
3. Отметка ✅ показывает активный сценарий.

![Telegram /start: приветствие и список сценариев](screenshots/tg-start-scenarios.png)

*Стартовое сообщение с human-readable названиями сценариев и активным промптом ✅.*

---

## 📤 3. Как отправить файл на аудит

1. Запишите аудио или видео звонка/встречи.
2. В чате с ботом нажмите скрепку и выберите файл.
3. Поддерживаются форматы: mp3, mp4, ogg, wav, m4a, mov и другие, которые Telegram распознаёт как аудио/видео.
4. Дождитесь сообщений:
   - «Файл получен. Скачиваю…»
   - «Анализ готов. Отправляю результат…»
5. Получите готовый Markdown-аудит с оценкой по критериям.

![Telegram: аудит sales-call после отправки аудио](screenshots/tg-audio-sales-call-audit.png)

*Результат: Markdown-аудит с процентом, статусами по критериям и рекомендациями.*

---

## 📋 4. Что входит в аудит

Результат зависит от активного сценария. Типичная структура:

- **Общая оценка** — процент и краткий вердикт.
- **Пункты по критериям** — статус ✅/⚠️/❌, обоснование с цитатой, рекомендация.
- **Итоговые статусы** — сводка всех критериев одной строкой.
- **Финальный вердикт** — например, «Рекомендую доработать.»

> 📌 Бот не придумывает цитаты. Все обоснования строятся на тексте транскрипта.

## 🚫 6. Дневной лимит обработок

Для защиты публичного демо каждый пользователь может отправить **не более 5 успешных
обработок в сутки**. Лимит считается по telegram user id.

При превышении бот ответит:
> «Лимит обработок на сегодня исчерпан (5). Попробуйте завтра.»

> 📌 Администратор (telegram user id из `ADMIN_USER_ID`) exempt от лимита.

---

## ⚠️ 7. Ограничения

Бот **не умеет**:
- обрабатывать текстовые сообщения (кроме команд);
- редактировать или удалять уже отправленные аудиты;
- гарантировать ответ нейросетью при её недоступности — в этом случае придёт
  статический fallback-ответ с объяснением;
- различать голоса идеально: качество диаризации зависит от записи и AssemblyAI.

## ❓ 8. Частые вопросы

**Q: Можно ли отправить голосовое сообщение?**
A: Да, если Telegram распознаёт его как аудио/голосовое. Лучше отправлять файлом (mp3/ogg) для сохранения качества.

**Q: Почему оценка не 100%?**
A: LLM оценивает по строгим критериям. Даже хороший звонок может получить ⚠️ или ❌,
если какой-то блок раскрыт слабо или отсутствует.

**Q: Как сменить сценарий аудита?**
A: Только администратор может сменить активный промпт в `/admin`. Обычный пользователь
использует текущий активный сценарий.

**Q: Где посмотреть историю обработок?**
A: В операторской панели `/admin/executions` — доступно администраторам.
