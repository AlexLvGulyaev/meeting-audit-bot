# 🧭 Маршрут проверки демо — Meeting Audit Bot

Как быстро убедиться, что аудит звонков работает: отправить запись
в Telegram и получить структурированный аудит, затем посмотреть
панель оператора в демо-режиме.

## 🧭 1. Маршрут проверки

1. **Открыть** [бота в Telegram](https://t.me/PEcb10_bot) →
   **отправить** /start → **увидеть** приветствие и список сценариев
   аудита.
2. **Отправить** аудио- или видеозапись звонка → **дождаться**
   обработки (30–120 секунд) → **получить** Markdown-аудит: заголовки,
   списки и пункты с эмодзи-статусами (✅ / ⚠️) по критериям
   активного сценария.
3. **Прочитать** аудит → **увидеть** оценку в процентах и разбор по
   критериям сценария sales-call; в `/help` — поддерживаемые форматы
   и активный сценарий.
4. **Открыть** [операторскую панель](https://meeting-audit-bot.alex-n8n.site/admin)
   → **нажать** «Войти в демо-режим (только просмотр)» → **увидеть**
   телеметрию обработки и настройки: активный LLM-провайдер, сценарий
   аудита, статистика.

## 🧭 2. Что ещё доступно

- Транскрибация с разделением по спикерам (AssemblyAI) — аудит строится
  по репликам, а не по всей записи одним куском.
- Сценарии аудита правятся в runtime: текст промпта меняется в панели,
  следующая запись обрабатывается уже по новому сценарию (см.
  [OPERATOR_GUIDE.md](https://github.com/AlexLvGulyaev/meeting-audit-bot/blob/main/docs/OPERATOR_GUIDE.md)).
- Полный скриншот-тур:
  [SYSTEM_DEMO.md](https://github.com/AlexLvGulyaev/meeting-audit-bot/blob/main/docs/SYSTEM_DEMO.md).
