# E2E-сценарии — Meeting Audit Bot

Документ описывает ручные E2E-проверки, которые проходились перед публикацией кейса. Все скриншоты лежат в `docs/screenshots/`, индекс — в `docs/MEDIA_INDEX.md`.

## Предварительные условия

- Проект развёрнут по `DEPLOYMENT_GUIDE.md`.
- Telegram-бот доступен и отвечает на `/start`.
- Админка доступна по `/admin/login`.
- Активный промпт по умолчанию — `onboarding`.
- E2E выполнялись в Chrome / Firefox на десктопе и в мобильном Telegram.

---

## 1. Telegram `/start` — onboarding и список сценариев

**Цель:** пользователь видит доступные сценарии аудита и активный промпт.

**Шаги:**
1. Открыть Telegram, найти бота `meeting-audit-bot`.
2. Отправить `/start`.
3. Убедиться, что бот прислал приветствие и список сценариев.

**Ожидаемый результат:**
- В списке 4 сценария с русскими названиями.
- Активный сценарий помечен ✅.
- Указано, кто может сменить активный промпт.

![Telegram /start: приветствие и список сценариев аудита](screenshots/tg-start-scenarios.png)

*Стартовое сообщение с human-readable названиями сценариев и активным промптом ✅.*

---

## 2. Telegram — отправка аудио и получение аудита sales-call

**Цель:** боевой проход аудита реалистичного B2B-звонка.

**Шаги:**
1. В админке `/admin` сменить активный промпт на `sales-call`.
2. В Telegram отправить тестовый аудиофайл (`examples/sample-b2b-sales-call-retail.ogg` или аналог).
3. Дождаться сообщения с аудитом.

**Ожидаемый результат:**
- Markdown-форматирование рендерится корректно (заголовки, жирный текст, списки).
- Нет обёртки ```Markdown ... ```.
- Итоговая оценка 87,5% (7 ✅, 1 ⚠️ по критерию «Следующий шаг»).
- Последняя строка — вердикт «Рекомендую доработать.».

![Telegram: аудит sales-call с оценкой 87,5%](screenshots/tg-audio-sales-call-audit.png)

*Результат аудита B2B-звонка: оценка 87,5% (7 ✅, 1 ⚠️) и структурированный Markdown-ответ.*

## 4. Админка — авторизация

**Цель:** вход по токену работает.

**Шаги:**
1. Открыть `/admin/login`.
2. Ввести `ADMIN_TOKEN`.
3. Нажать «Войти».

**Ожидаемый результат:**
- Редирект на `/admin`.
- В сайдбаре видно имя/роль пользователя.

![Страница входа в /admin: полный токен и демо-вход](screenshots/admin-login.png)

*Два пути входа: форма полного токена и одно-кликовой demo-режим (read-only).*

## 5. Админка — dashboard

**Цель:** dashboard показывает состояние системы.

**Шаги:**

**Ожидаемый результат:**

## 6. Админка — смена активного промпта

**Цель:** администратор может переключить сценарий аудита.

**Шаги:**
1. На `/admin` кликнуть селектор «Активный сценарий аудита».
2. Выбрать другой промпт, например `sales-call`.
3. Убедиться, что название отображается человекочитаемо.

**Ожидаемый результат:**
- Список раскрыт.
- Новый промпт выделен/подсвечен.
- После сохранения появляется подтверждение.

![Админка: смена активного сценария аудита](screenshots/admin-change-prompt.png)

*Селектор активного сценария с human-readable названиями и подтверждением сохранения.*
